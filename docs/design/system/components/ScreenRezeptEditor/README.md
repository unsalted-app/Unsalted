# ScreenRezeptEditor

Muster für Bildschirm 3 (Rezept bearbeiten): Entwurf im gestrichelten Rahmen, zweizeilige Zutatenzeilen, Einfrieren als Markenmoment.

Template `FormPageTemplate` mit `header`, `FormSections`, `bottomBar`. Neu gegenüber heute: Live-Vorschau mit Gesamt, pro Portion und pro 100 g (Design-Notiz aus `docs/status.md`), Zutatenzeile am Handy zweizeilig statt vier Felder in einer Reihe, gestrichelte Unterstreichung nicht verknüpfter Zutaten, Umsortieren auch ohne Ziehen. Beispieldaten sind erfunden.
