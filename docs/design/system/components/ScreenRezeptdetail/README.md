# ScreenRezeptdetail

Muster für Bildschirm 4–6 (Rezeptdetail mit Nährwerten und Mengenrechner): Lesen auf Armlänge in der Küche.

Template `DetailPageTemplate` mit `DetailSections`. Neu gegenüber heute: Rezepttitel als `display` im Inhalt, Fassungsleiste statt Auswahl-Chips, Kennzahlenleiste, Mengen in fester Spalte vor dem Namen, Deklarationstabelle. Reihenfolge der Abschnitte wie heute (Fassungen, Beschreibung, Nährwerte, Zutaten, Schritte) ist offen: das Muster stellt Zutaten und Schritte vor die Nährwerte. Beispieldaten sind erfunden.
