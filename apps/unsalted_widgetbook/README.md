# unsalted_widgetbook

Komponenten-Katalog von unsalted (Teil 1.2, [Widgetbook](https://pub.dev/packages/widgetbook)):
alle Tokens, Komponenten und Templates aus `packages/unsalted_design`, je hell/dunkel
und Handy/Tablet. Komponentenname = Dart-Klasse, Anwendungsfall = Figma-Variante
(`docs/design/components.md`).

```sh
flutter run -d macos
```

Tests: WB-01 (jeder Anwendungsfall baut in allen vier Varianten), WB-02 (jede
Komponente der Tür steht im Katalog), WB-03 (die App startet).
